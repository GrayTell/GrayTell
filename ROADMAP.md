# Roadmap

## Active Focus

### Weekly Research Papers

**Every week we drop a new research paper.** This is a core part of GrayTell's mission — we don't just build, we publish. Each paper covers:

- Architecture decisions and trade-offs
- Benchmark results across providers and models
- Novel techniques we developed (e.g., the Ollama NDJSON→SSE adapter)
- Real-world findings from running a multi-provider AI agent at scale

Papers are published in the [`papers/`](./papers/) directory and announced on GitHub Releases.
